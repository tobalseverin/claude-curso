# 02 — TRD: Cursos

Course catalog at `curso-claude.p113.io`, one folder per course. The repository is a fork of [luongnv89/claude-howto](https://github.com/luongnv89/claude-howto), the source of the Claude Code course. How the site is built: [`sitio/README.md`](../sitio/README.md). How the Claude course and its upstream sync work: [`curso/README.md`](../curso/README.md).

## Stack

- Claude Code course: static HTML generated by the upstream `scripts/build_website.py` (Python, run with `uv`) plus the translation pipeline in `curso/`.
- Other courses: static files in `sitio/cursos/<folder>/`, served as they are.
- Catalog: a page rendered from `sitio/cursos.json`.
- No backend, no database, no environment variables.

## Deploy

| | |
| --- | --- |
| Target | Own server: **wonki** (`ssh cs@wonki.p113.io`) |
| Type | Static site, no PM2 |
| Vesta user | `p113` |
| Domain | `curso-claude.p113.io` (Let's Encrypt SSL managed by Vesta) |
| Document root | `/home/p113/web/curso-claude.p113.io/public_html`, a plain directory, as set in the Vesta nginx config |
| Active folder | Same as the document root |
| Releases | `/home/p113/releases/`, outside the document root |
| Candidate | `/home/p113/releases/curso-claude-<YYYYMMDD-HHMM>/`, new and empty for every deploy |
| Backup | `/home/p113/releases/curso-claude-backup-<YYYYMMDD-HHMM>/`, a copy of `public_html` before activation |

Convention agreed on 2026-10-29: the other p113 sites (`stat.p113.io`, `wiki.p113.io`) use a plain `public_html` with no releases or symlinks, so this site keeps `public_html` as a directory and does not change the structure Vesta generated.

### Steps

1. Build locally: `sitio/build.sh`. The output is `build/site/`: catalog at `/`, Claude at `/claude/` and `/claude/en/`, each other course in its folder, and redirects from the old Claude URLs.
2. Upload `build/site/` into the candidate folder over SSH and give ownership to `p113`.
3. Back up `public_html` into the backup folder, as `p113`.
4. Activate, as `p113`: `rsync -a --delete <candidate>/ /home/p113/web/curso-claude.p113.io/public_html/`.
5. Check `https://curso-claude.p113.io/`, `/claude/`, `/claude/en/` and every course at 390 and 1440 px.

### Rollback

As `p113`: `rsync -a --delete <previous release or backup>/ /home/p113/web/curso-claude.p113.io/public_html/`.
